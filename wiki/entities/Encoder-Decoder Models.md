# Encoder-Decoder Models

Encoder-decoder models handle **sequence-to-sequence (seq2seq)** tasks, transforming an input sequence into a different output sequence.

## Architecture and Flow
1.  **Encoder:** Processes the input sequence bidirectionally and compresses it into a dense context vector (also known as a hidden state representation).
2.  **Decoder:** Takes the context vector generated by the encoder and generates an output sequence token-by-token. The decoder uses **Cross-Attention**, where it pays attention to the encoder outputs while generating predictions, combined with its own masked causal self-attention over previously generated tokens.

## Key Characteristics
*   **Training Methodology:**
    *   **Denoising Autoencoding:** The input text is artificially corrupted (e.g., masking, deleting, or shuffling tokens), and the model is trained to reconstruct the original sequence.
    *   **Text-to-Text Formulation:** All NLP tasks (even classification) are framed as text-to-text generation tasks. For example, "Translate English to French: The house is big" outputs "La maison est grande."
*   **Strengths:** Highly flexible and powerful for input-to-output transformations where the output structure differs significantly from the input.

## Common Use Cases
*   Machine Translation
*   Text Summarization
*   Paraphrasing

## Notable Examples
*   **T5** (Text-to-Text Transfer Transformer)
*   **BART** (Bidirectional and Auto-Regressive Transformers)
*   **MarianMT**
*   **mBART**

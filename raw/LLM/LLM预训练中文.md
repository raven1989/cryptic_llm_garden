二、数据清洗与处理流程

中文预训练语料从原始数据到可用训练数据，通常需要经过以下处理流程：
1. 数据收集

网页数据：Common Crawl中文部分、自建爬虫
百科/知识类：百度百科、维基百科中文、专业百科
书籍/文献：中文书籍、学术论文（arXiv中文、知网等）
社交媒体/论坛：知乎、贴吧、论坛帖子等
代码：GitHub中文项目、StackExchange
2. 清洗与去重

规则筛选：去除HTML标签、广告、导航栏、低质量文本
去重处理：
精确去重（URL/文档级别）
Min-Hash算法进行近似去重
语义级去重（去除重复或高度相似内容）
隐私过滤：去除身份证号、手机号、银行卡号等敏感信息
去污染：去除测试集/基准数据污染，避免数据泄露
3. 质量评估与筛选

质量打分模型：训练分类器对文本质量进行评分（如教育价值评分、语言流畅度评分）
主题分类：对文本进行领域分类，便于后续配比
语言识别：确保中文纯度，过滤非中文或中英混杂严重的低质量文本
4. 数据合成（Data Synthesis）

针对数学、代码、科学推理等能力，越来越多模型采用合成数据：
数学：合成文档、CoT推理链、基于Lean的形式化数学
代码：合成代码文档、CoT推理
科学：合成科学推理数据
类o1反思数据：具备反思和验证的思维链数据
案例：YuLan-Mini完整开源了数据处理流程，包括"数据收集 → 去重/规则筛选 → 主题分类 → 质量打分和去污染 → 数据合成 → 数据课程"。
三、数据配比策略

1. 通用配比参考（以LLaMA为基准）

目前业界关于预训练数据的配比尚未达成广泛共识，但LLaMA的配比成为重要参考：
表格


数据类型	比例	说明
网页数据	>80%	提供丰富的世界知识
代码（GitHub/StackExchange）	~6.5%	代码密集型数据
书籍	~4.5%	长篇连贯文本
科学论文（arXiv等）	~2.5%	科学数据
不同的大语言模型在训练数据类型分布上的差距很大，截至2025年2月，业界关于预训练数据的配比还没达成广泛的共识。
2. 中英数据配比

中文为主模型：中文:英文 ≈ 9:1 或更高（如度小满轩辕金融大模型采用中文9:1英文）
双语平衡模型：如Qwen系列、Baichuan系列等，通常中英文混合训练，英文比例较高以保持英文能力
中文增量预训练：在英文基座模型（如LLaMA）上增量预训练时，中文数据比例会逐步提高
3. 分阶段数据课程（Data Curriculum）

先进模型普遍采用分阶段训练策略：
YuLan-Mini的数据课程示例：
初期：中文知识类优先（百科、书籍、论文等）
中期：逐渐提升综合类中文语料（网页内容、新闻类等）
后期：逐渐提升垂类语料（如金融、代码、数学等）
退火阶段（Annealing）：使用高质量数据（如精选书籍、维基百科、合成推理数据）进行最后阶段训练
度小满轩辕金融大模型的训练过程："中文知识类优先：百科、书籍、论文等 → 逐渐提升综合类中文语料：网页内容、新闻类等 → 逐渐提升金融垂类语料 → 英文数据持续训练"，最终"三项能力均随训练过程提升"。
4. 推理/代码/数学专项配比

针对推理能力优化的模型（如Skywork-OR1、DeepSeek-R1系列）：
大幅提升代码和数学数据比例
引入合成CoT（Chain-of-Thought）数据
使用形式化数学数据（如Lean）
采用类o1的反思式思维链数据
四、质量评估与去污染

1. 质量评估维度

语言质量：语法正确性、流畅度、信息密度
教育价值：文本的知识含量和教育意义（Fineweb-edu系列采用此标准）
领域相关性：是否符合目标领域需求
多样性：避免单一来源或主题过度集中
2. 去污染（Decontamination）

N-gram匹配：去除与评测基准（如MMLU、C-Eval、GSM8K等）重叠的训练数据
模糊匹配：检测改写或轻微修改的测试数据
严格隔离：训练数据与测试数据完全隔离
五、行业最新动态（2025-2026）

1. 中文语料库建设政策层面

国家层面重视：2025年《求是》杂志发文指出"中文语料库建设呼唤新格局"，强调新型语料库"规模极其浩大、范围极其广博"的特点。
教育部支持：已支持建设30余项关键领域语料库。
供给不足问题：目前国际主流大模型训练语料以英文为主，占比超过90%，中文语料库供给量难以满足快速增长的大模型训练需求。
2. 开源社区进展

OpenCSG中文语料：发布Fineweb-edu-chinese-v2（约420B tokens），推动中文高质量语料开源。
Skywork-OR1：昆仑万维开源32B推理模型，同时开源训练数据集和完整训练代码，成为中文推理模型重要参考。
YuLan-Mini：人大高瓴人工智能学院开源2.4B模型，完整开放预训练细节、逐阶段数据配比和中间模型，仅使用1.08T Tokens达到竞争力水平。

六、关键挑战与建议

当前挑战

中文语料占比低：国际主流训练语料中英文占比超90%，中文优质语料相对稀缺
质量参差不齐：网页数据噪音大，需要复杂的清洗和质量评估流程
领域不平衡：通用语料多，专业领域（如法律、医疗、金融）高质量语料少
数据配比共识不足：不同模型采用不同配比，缺乏统一的最佳实践标准
实践建议

分层建设：基础通用语料 + 领域专业语料 + 合成推理数据
质量优先：采用教育价值评分、质量打分模型等机制，宁可减少规模也要保证质量
数据课程：分阶段调整数据配比，初期注重知识积累，后期强化推理和代码能力
去污染严格：建立与评测基准的隔离机制，确保评估公平性
开源共享：积极参与开源语料库建设（如MNBVC、OpenCSG等项目）
如需进一步了解某个具体语料库（如SkyPile-150B、Fineweb-edu-chinese-v2）的技术细节，或特定领域（金融、法律、医疗）的语料构建方法，可以继续深入探讨。
